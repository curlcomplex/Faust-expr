# Clap v0.1

Independent electronic clap inspired by the documented behavioural roles of Syntakt CP Vintage: clustered sub-attacks, diffuse noise tail, optional FM body and compact macro controls. It is not recovered Elektron code or circuit topology.

Seven non-pitch synthesis parameters are deliberately retained: **Spacing, Punch, Decay, Balance, Body, Body Envelope, Drive**. Tracker may display Body/Body Envelope as the paired fifth column under its existing seven-inside-six policy. Pitch, gate and velocity remain performance inputs.

Diagnostics preserve three hypotheses: single-burst instead of cluster, no diffuse tail, and no FM body. Qualification must keep them audible and measured rather than assuming the fuller design wins.
