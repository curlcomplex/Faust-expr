# Analog-style snare

Activated by #47. Independent conventional/electronic snare: two tonal body modes, separately filtered noise, clustered crack and optional drive. It deliberately does not reuse `snare-pm`'s PM body. SD Classic/Hard/Natural/FM are listening/reference leads only; no proprietary circuit or macro mapping is asserted.

Pitch is a performance input. Six visible synthesis columns: **Balance / Crack / Decay / Noise Color / Tone / Drive**. All musical controls and velocity latch at onset; note-off does not choke the one-shot.

Qualification must compare useful territory against `snare-pm`. If this machine cannot establish a distinct conventional body/noise/crack role, nix it rather than preserve catalogue redundancy.
