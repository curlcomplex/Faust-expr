# CZ v1 source checkpoint

First audible/reusable phase-distortion source for issue #98.

The CZ oscillator equations are adapted from `magnetophon/VoiceOfFaust` `followerOscillators.lib`, where the code is credited to Mike Moser-Booth and the Faust port to Bart Brouns. VoiceOfFaust is GPL-3.0; keep this provenance attached to this implementation. This source is therefore not assumed suitable for relicensing without an explicit licensing decision.

Scope: square-like and sine-pulse phase-distortion source, DCW/index control, simple playable envelope wrapper. Not yet the complete Casio line/wave-pair/DCO-DCW-DCA envelope architecture, ring/noise modulation, key follow or dual-line voice.
