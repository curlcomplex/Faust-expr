# Required-output and real online-compile qualification

Continues the positive first persistent-state prototype, without changing that tested source. A strict hash-pinned adapter removes diagnostic input planes from all four timing arms, leaving the same stereo named output taps and common observer workload. This avoids falsely preserving performance by forcing the whole-graph reference to materialize unnecessary internal values. The existing real product renderer supplies retained full tap/host captures. A no-edit negative verifies that topology B actually changes the master.

The same 19 static comparisons and 19 continuous precompiled A/editable-B/optimized-B/editable-A/A state tests run with unchanged numerical and cost-screen bounds. The original 46 native retained-module tests, 37 public lab tests and actual Faust probe are retained. Passing the first two gates runs eight new cases: real Clang graph-kernel compilation while editable shared-state audio continues, followed by optimized adoption, stale older-result rejection, cache return and a deliberately failed compile. Every generated module/state header remains the same. No copying, reinitialization, background writes to live state or two engines advancing it concurrently.

Four shapes run normally and with a bounded number of copies calibrated toward 75% of the optimized per-block budget. This is a stress attempt, not a guaranteed hardware utilization level. Exact achieved optimized/editable compute fractions and late synthetic deadlines are reported. It uses a normal scheduled thread on a VM, not Core Audio or Audio Workgroups. A numerical success is not a deadline pass. A temporary editable mode that exceeds the budget remains a limitation even when optimized execution recovers.

The online compiler starts only after the edit, emits the actual new routing and statically composes Faust-generated frame routines. The precompiled B variant used in the earlier continuity test is not used for this first online adoption. A source command log, generated code, binary, complete tap waveform and observed revision timeline are retained. A separate stock LLVM per-module oracle follows the actual sample timeline after capture, so reference computation does not add to the live timing load.

All code/state/plan owners remain alive until the audio thread joins. That is a bounded safe experiment lifetime, not a completed production retirement algorithm. The schema-negative checks incompatibility before use; it does not test arbitrary compiler-layout translation. No actual device, GUI, new modules, changed DSP source, polyphony/MIDI/VM/CV completeness, bitcode cache acceptance or multicore result. No current unified renderer or production default is replaced.
